# Vue 3 + Vite

This template should help get you started developing with Vue 3 in Vite. The template uses Vue 3 `<script setup>` SFCs, check out the [script setup docs](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) to learn more.

Learn more about IDE Support for Vue in the [Vue Docs Scaling up Guide](https://vuejs.org/guide/scaling-up/tooling.html#ide-support).

## Skill Claude: Humanities Writing Companion

O diretório `.claude/skills/humanities-writing-companion/` contém a skill
[Humanities Writing Companion](https://github.com/tizzy916/humanities-writing-companion)
(Cong Shen, CC BY-NC 4.0). O Claude Code carrega-a automaticamente neste
repositório e ativa-a em tarefas de escrita académica em humanidades:
afinar perguntas de investigação, mapear leituras, planear e redigir
argumentos, rever capítulos preservando a voz do autor e responder a
revisores. Proveniência e instruções de atualização em
[`UPSTREAM.md`](.claude/skills/humanities-writing-companion/UPSTREAM.md).
